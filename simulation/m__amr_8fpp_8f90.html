module  m_amr
 Block-structured AMR: up to amr_max_blocks refined blocks (2:1 or 4:1 per amr_ref_ratio), optionally nested to amr_max_level, advanced with the shared solver via grid-state swap and conservatively coupled to each block's parent level (ghost prolongation, Berger-Colella flux reflux, restriction) and dynamic regrid.
