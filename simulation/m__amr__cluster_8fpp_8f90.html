module  m_amr_cluster
 Berger-Rigoutsos clustering of a sparse tag list into separated block boxes, identically on every rank: tag signatures, bisection, canonical Morton order and min-separation merge.

impure subroutine m_amr_cluster::s_cl_reduce_depth (nbat, bsig, bofs, blen, bnov, bwide, bovr)
 Sum the depth's batched signatures across ranks. Wide nodes (every rank overlaps) ride one ALLREDUCE. Narrow nodes reduce point-to-point within their small rank brick: members send to the root bovr(1,:), which sums and sends the total back. Both ends enumerate nodes in the same global order, so one aggregated message per peer per phase matches without negotiation.
impure subroutine m_amr_cluster::s_cl_union (alo, ahi, nacc)
 Union the per-rank accepted boxes (rank-local subtrees are walked only by their owner). Rank order is not serial acceptance order; the Morton sort that follows removes the dependence. alo/ahi grow to the union (the cap applies to the merged set).
impure subroutine m_amr_cluster::s_cl_bisect (tags, ntag_in, reduce, alo, ahi, nacc, capped)
 Level-order Berger-Rigoutsos descent: accepts boxes into alo/ahi(:, 1:nacc). Every shared node of a depth rides one reduction, so the collective count is O(tree depth). A child's overlapping ranks are a subset of its parent's, so every rank walks the whole shared subtree in the same order. Children are appended past ncur and shifted down when the depth closes (peak occupancy 3*ncur <= the 4*cap + 8 the arrays carry).
impure subroutine m_amr_cluster::s_cl_morton_sort (alo, ahi, nacc)
 Sort boxes by the Morton key of lo so the merge input depends on the box set alone, not on the rank-dependent acceptance order. Accepted boxes are disjoint, so the keys are distinct; the sort is stable for any collision.
impure subroutine m_amr_cluster::s_cl_merge (alo, ahi, nacc)
 Min-separation merge: two boxes are separated only if some active dim's gap reaches thr; else fuse to their bounding box. The fusion sequence is the linear walk (scan in list order, fuse the first too-close pair, restart), reproduced exactly with O(1) unlinking and a binned candidate search: a too-close partner of i lies within the 3^d bins around i's lo when the bin width is ext_max + thr, and the minimum surviving index among candidates is the first one a linear walk meets. After fusing (i, j) only box i changed, so the walk re-tests earlier survivors (minimum index first), then later ones, then resumes at the survivor's successor. Bins are rebuilt when a grown box outgrows the cell width.

impure subroutine, public m_amr_cluster::s_amr_cluster (tags, ntag_in, boxes, nboxes, reduce)
 Cluster a sparse tag list tags(1:3, 1:ntag_in) of level-0 cell coords into separated block boxes, identically on every rank. Berger-Rigoutsos bisection until a box's tag efficiency reaches amr_cluster_eff (or it is atomic or the amr_max_blocks cap is hit), then merge boxes whose amr_buf-padded extents come within buff_size. Boxes are raw tagged extents; the caller pads, clamps and size-caps each. reduce: tags is this rank's local list and node signatures are reduced across ranks; otherwise tags is already replicated.
