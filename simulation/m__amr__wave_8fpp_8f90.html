Modules

module  m_amr_wave
 MPI point-to-point waves for AMR exchange: post all receives, pack, post all sends, wait once. Pooled waves list transfers on a send/receive side and s_amr_wave_close lays them out contiguously per peer; both ranks enumerate the same transfers in the same order, so no metadata is exchanged. Pools are caller-owned (device-resident under rdma_mpi).
