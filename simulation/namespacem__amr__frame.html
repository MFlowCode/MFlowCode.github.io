Extend one axis of the installed fine grid into the ghost shell with the same parent-cell bisection the interior uses: boundary jg belongs to parent cell cl = isect_lo + floor(jg/rr), and k = modulo(jg, rr) picks the rr-way split. The parent boundaries are gcb for a level-1 block; a level>=2 block's parent grid is rebuilt from replicated metadata (the parent's own arrays exist only on its owner). Blocks stay buff_size inside the domain, so every ghost parent is an in-domain cell.
