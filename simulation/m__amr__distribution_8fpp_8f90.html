module  m_amr_distribution
 Rank decomposition, box arithmetic and block ownership (SFC cut, owner lookups, owned-block lists).

Functions/Subroutines

pure subroutine, public m_amr_distribution::s_amr_rank_decomp (r, sidx, ext)
 Rank r's coarse-grid decomposition (start_idx + local extent m/n/p), computed O(1) from its cartesian coords. The domain cart is MPI_CART_CREATE(reorder=.false.), so ranks keep MPI_COMM_WORLD order and coords are row-major in r. The per-dim split is the integer split-with-remainder of s_mpi_decompose_computational_domain.
impure subroutine, public m_amr_distribution::s_amr_validate_decomp ()
 Guard: the computed decomposition must reproduce this rank's actual one (each rank checks itself, so all r are covered).
pure integer function m_amr_distribution::f_amr_cell_coord (g, base, rem)
 Closed-form inverse of the per-dim split in s_amr_rank_decomp: the cart coord owning global coarse cell g, with base=(gd+1)/pd, rem=mod(gd+1,pd). Exact for g in [0,gd]; callers clamp for out-of-range g (ghost reach).
pure subroutine m_amr_distribution::s_amr_coord_range (blo, bhi, clo, chi)
 Per-dim contiguous rank-coord range [clo:chi] whose owned coarse slab meets box [blo:bhi], clamped to [0,pd-1]. The boundary coords' coarse_range is extended by buff_size at the domain edge (s_amr_rank_coarse_range), and clamping reproduces both the interior (scatter) and coarse_range (gather) sets. Collapsed dims contribute coord 0.
pure subroutine, public m_amr_distribution::s_amr_ranks_overlapping (blo, bhi, ranks, nr)
 Ascending rank list overlapping coarse box [blo:bhi]: the coord brick is enumerated cx->cy->cz so r = cx*(Py*Pz)+cy*Pz+cz ascends, reproducing the 0..num_procs-1 scan order. Owner not excluded. Caller sizes ranks(:) >= f_amr_overlap_count.
pure logical function, public m_amr_distribution::f_amr_rank_overlaps (blo, bhi, r)
 Does rank r's subdomain overlap coarse box [blo:bhi]? Answers membership without enumerating the overlap set, which is O(num_procs) for a box spanning the machine.
pure integer function, public m_amr_distribution::f_amr_overlap_count (blo, bhi)
 Overlap count only (allocation sizing), = product of the per-dim coord-range widths.
pure subroutine, public m_amr_distribution::s_amr_rank_coarse_range (r, crlo, crhi)
 Rank r's contiguous owned coarse-cell range per dim: the interior plus buff_size ghosts where the subdomain touches the domain edge. One span, so box intersections identify contributors without a per-cell scan.

impure subroutine m_amr_distribution::s_amr_block_cost (cost)
 Per-block cost over each block's level-0 footprint (1 per cell + K_ib per IB-marked cell), summed over each rank's owned coarse cells and replicated by one MPI_ALLREDUCE(SUM).
subroutine, public m_amr_distribution::s_amr_sfc_cut (keys, wt, n, cut, owner)
 Cost-weighted SFC partition of n items into num_procs contiguous Morton-key ranges: walk the key-sorted items (stable merge sort) and advance the owner rank when the running weight crosses the next even share. Writes owner(1:n) and cut(0:num_procs-1) (running Morton upper bound per rank; ranks with no item inherit the predecessor's bound, so cut is non-decreasing).
pure subroutine, public m_amr_distribution::s_amr_sort_by_key (keys, n, ord)
 ord(1:n) = item indices in ascending key order. Stable iterative bottom-up merge sort, a pure function of the input so every rank derives identical orders from replicated keys (differing assignments would deadlock or abort).
impure subroutine, public m_amr_distribution::s_amr_refresh_my_blocks ()

impure subroutine, public m_amr_distribution::s_amr_refresh_lists ()
 Rebuild the epoch-keyed block lists when the mesh epoch has moved (one O(global blocks) walk per regrid, not per RK stage). Also caches the parent index (f_amr_parent_block is an O(global blocks) scan) and the children adjacency used by s_amr_sibling_face_weights.
impure subroutine m_amr_distribution::s_amr_place_overlap (k, g, vol, rk, nr)
 Coarse-side overlap per rank of block k's region grown by g coarse cells: level 1 against the level-0 rank bricks, level >= 2 against the owners of the level-(l-1) blocks. Adds into vol(0:) and lists touched ranks in rk(1:nr); the caller zeroes vol(rk(1:nr)) after use.
impure subroutine m_amr_distribution::s_amr_place_owner (key, wt, aidx, na, own)
 Owner-aware placement (amr_place_owner) of one level's na blocks (slots aidx, weights wt, Morton keys key): each block goes to the rank owning most of the coarse cells under it. A rank above (1 + place_tol) x the mean sheds its last blocks in Morton order, first to the least-loaded rank next to the block, then to the least-loaded rank anywhere, never pushing the receiver above the cap. Replicated inputs in a fixed order, so every rank computes the same owners.
impure subroutine, public m_amr_distribution::s_amr_assign_block_owners ()
impure subroutine, public m_amr_distribution::s_amr_adopt_block_owners (own)
 Install a recorded owner table instead of recomputing it (restart at the writer's rank count): the cost weights read live state (body markers) that differs between the regrid before the write and the restart. Each level's cut is the running max Morton key of each rank's blocks; s_amr_validate_owner rejects a table not contiguous in that order (unless amr_place_owner).
impure subroutine m_amr_distribution::s_amr_report_balance (wt, maxlev)
