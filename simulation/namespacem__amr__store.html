impure subroutine s_amr_st_move_slot (src, dst)
 Move one local slot's store data src -> dst on the device, in place (a staging copy would transiently double the store). Ascending-source order (s_amr_compact_store) guarantees dst's old contents are consumed. The host copy goes stale, the store's normal state between rebuilds.
impure subroutine s_amr_compact_store ()
 Re-densify the local index space after every reconcile so amr_loc_n tracks the live count instead of ratcheting up with SFC window shifts and migration slots (capacity then plateaus at the rebuild transient). Moves are device-side and in place in ascending old-index order: each destination is <= its source and below every pending source. Called at the end of s_amr_reconcile_slots, after the rebuild's overlap carry-forward (which reads amr_stor_st at old indices) has finished.

impure subroutine s_amr_st_reserve (nloc)
