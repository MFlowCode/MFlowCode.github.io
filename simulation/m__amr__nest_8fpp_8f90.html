module  m_amr_nest
 Hierarchical child nesting for AMR regrid: each level's children are tagged by the density-gradient sensor on the old parent-level fine solution, clustered, and replayed in rank-invariant order. Also holds the shared tag sensor.

impure subroutine m_amr_nest::s_amr_nest_close_seams (boxes, par, box_level, clo, nboxes, lev)
 Join children across parent seams. Where parent pb sits on parent pa's high face in dim d, and a child of each ends at its nesting window there with the same transverse extents, both are brought to the shared parent face (s_amr_nest_reach): the boxes on it become a fine-fine seam pair and the strip between the children is refined. The parent patch of such a box reaches amr_cpat_mar cells into the parent's ghosts, which the parents' own seam exchange fills. A closure that leaves a neighbour with a partly shared face is undone (a tile joins only if the tiles beside it do), as is one the block pool has no room for. One dim at a time, so a later dim sees the new extents and can close the corner where four parents meet. Replicated inputs: rank-invariant. Not with IB.
