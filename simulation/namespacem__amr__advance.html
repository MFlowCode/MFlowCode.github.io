impure subroutine, public s_amr_setup_ib ()
 Compute the fine-grid IB state (markers/ghost points/levelset) for every active block from the body geometry (static-body AMR), once after the coarse IB setup: swap grid and IB globals to each owned block, run the fine IB pipeline, restore.
impure subroutine s_amr_ib_correct_fine (q_prim_b, pb_in, mv_in)
 Apply the IB state correction on the current fine block after its RK update, mirroring the coarse s_ibm_correct_state. amr_cur is set by the caller.
impure subroutine s_amr_update_mib_fine ()
 Rebuild the current fine block's IB state from the moving body's position (prescribed motion, moving_ibm==1) by reusing the coarse s_update_mib on the swapped-in slot. Must precede s_amr_ib_correct_fine.
impure subroutine, public s_amr_fine_stage_advance_batched (s, coefs, bc_type, q_t_sf, pb_in, rhs_pb, mv_in, rhs_mv, t_step)
 Batched fine advance: owned fine blocks are advanced in batches of up to amr_bat_lim blocks of the same level and (padded) extent, stacked two ghost shells apart along the last active dimension, so one s_compute_rhs call and one RK kernel cover a batch. Blocks are independent, so grouping order is free. Members read the leader's coordinate arrays in the non-stacked dimensions (see s_amr_init_report).
impure subroutine s_amr_form_batch (i, my, done)
 Start a batch at leader my(i): add later same-level blocks that fit the leader's extent, wasting <= amr_bat_pad of the member's cells; marks members done.

impure subroutine s_amr_bat_layout ()

impure subroutine s_amr_fine_rk_update_batch (nb, q_rhs, c1, c2, c3, c4, dt_in)
 Device RK stage update over the batch: q = (c1*q + c2*q_stor + c3*dt_in*rhs)/c4 (compute in wp, store stp), reading each member's rhs at its slab offset. Keep in lockstep with the non-IGR rk_coef form in s_tvd_rk (m_time_steppers).
