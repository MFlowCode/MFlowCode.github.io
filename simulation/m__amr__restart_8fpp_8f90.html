module  m_amr_restart
 AMR fine-level restart I/O: writes/reads the fine-level restart file alongside the level-0 restart (serial per-rank unformatted files, or one shared MPI-IO file under parallel_io).

impure subroutine, public m_amr_restart::s_write_amr_restart (t_step)
 Write the fine-level restart file for save step t_step alongside the level-0 restart: the writing rank count, the active block count, and per block its box + level and each rank's fine conservative state. Serial: one unformatted file per rank in its level-0 step directory. Parallel: one shared MPI-IO file (header [-np, nboxes, sys_size, ratio, max level, word bytes], then per block a box+level header, a 4-int ownership record [owner+1, m, n, p], then the ranks' blocks concatenated in rank order). At the same rank count the ownership record must match on read; a different rank count repartitions.
impure subroutine, public m_amr_restart::s_read_amr_restart (restored)
 Restore the fine level from the AMR restart file at t_step_start (n_start under cfl_dt), if one exists: rebuild each saved block via s_set_amr_fine_geometry and read the fine state (exact stp round-trip). parallel_io repartitions across rank counts; serial needs the writing rank count. restored = false on a fresh start (the caller prolongs from coarse); a missing file aborts. Collective.

impure subroutine m_amr_restart::s_amr_restart_read_serial (file_loc)
 Serial (per-rank files) read: every block's region, level and, where this rank owned it at write (rm >= 0), its fine state. The presence flag is verified against this run's ownership once the owners are rebuilt.
impure subroutine m_amr_restart::s_amr_restart_read_parallel (file_loc)
 Parallel (MPI-IO) read. The writer's rank count sets only the file layout: each block's data is one contiguous chunk, so any rank count can read it; owners are re-assigned and each new owner reads its blocks. At the writer's rank count the file's ownership record must reproduce this run's decomposition.
