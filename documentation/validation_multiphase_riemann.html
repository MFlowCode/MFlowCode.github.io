Validation: Two-Fluid Shock Tube, Interface Advection and Phase-Change Equilibrium

Two-fluid flows: shock tube, interface advection, phase-change equilibrium

Status: water-air shock tube: validated. Interface advection: partially validated (open: a localized pressure error on coarse grids). Phase-change equilibrium: partially validated (equilibrium of the relaxed state only). Code: master at 5838b641c. Examples: examples/1D_kapilashocktube, examples/2D_advection, examples/1D_exp_tube_phasechange. Last run: 2026-11-24. See also Validation.

All tables were measured with GNU 13.3 (CPU, one rank, double precision); the A100 rows used NVHPC 25.11 (OpenACC, one GPU).

  • The solution converges to the exact one: the pressure error is first order, as expected with a shock, and the material interface sits within 0.02 cells of the exact contact on every grid.   • At 100 and 200 cells the uniform pressure and velocity hold to 3e-6 and 2e-9 across a density ratio of 1000 and a pi_inf contrast of 1e4 p0 over the whole flow-through: the scheme keeps the interface equilibrium.
  • The interface is not diffused beyond its initial smoothing: the mixed zone widens by 0.1 cells or less per flow-through up to 100 cells (0.4 cells at 200, where the disk travels 200 cells in each direction). The L1 error per unit interface length is about a tenth of a cell and falls as N^-0.4 in physical units; the initial profile is a fixed number of cells wide, so this is not the convergence of one solution.
  • Open: localized pressure error on coarse grids. At 50 and 64 cells the pressure error stays below 3e-6 for 0.4 flow-throughs and then jumps to 2.5e-3 p0 (250 Pa) in a patch of about 30 water cells that hold 1e-6 to 1e-4 of air, and travels with the disk. The onset coincides with a cell where a volume fraction undershoots to zero (6-equation) or below zero (the same case with the 5-equation model, where the error reaches 2.5e-2 p0 at 50 cells and stays at 2e-11 at 100). It does not change with the CFL number (0.2), the trace fraction (1e-6 to 1e-10), mp_weno (1.7e-3) or a disk path that avoids the box corner, and the A100 reproduces it to the digits shown. Relative to the water stiffness p0 + pi_inf the error is 2.5e-7. Cause not identified.

  • The relaxed state is in thermal and chemical equilibrium: every cell lies within 7e-4 K of the saturation curve after the expansion has evaporated 6.8 % more vapor, with all phases at one temperature to 1e-6.
  • The parameters give T_sat(101325 Pa) = 373.79 K against 373.12 K measured (a property of the fit, not of the solver).

Limits: the expansion is weak (the pressure falls by 420 Pa, 0.04 %), and only the equilibrium of the state is checked, not the wave speeds or the evaporated mass against a reference solution. Metastable and flashing cases are not covered.

Reproduce

./mfc.sh run examples/1D_kapilashocktube/case.py -t pre_process simulation post_process -n 1 -- -N 1000
python3 examples/1D_kapilashocktube/check_riemann.py examples/1D_kapilashocktube --case-args "-N 1000"
./mfc.sh run examples/2D_advection/case.py -t pre_process simulation post_process -n 1 -- -N 100
python3 examples/2D_advection/check_advection.py examples/2D_advection --case-args "-N 100"
./mfc.sh run examples/1D_exp_tube_phasechange/case.py -t pre_process simulation post_process -n 1 -- -me 3
python3 examples/1D_exp_tube_phasechange/check_saturation.py examples/1D_exp_tube_phasechange --case-args "-me 3"

The checkers take several run directories (and --case-args for each) to print the observed order. The shock tube and the expansion tube run in the test suite at a reduced size, as every registered example does; 2D_advection is on the skip list. No test was added.
