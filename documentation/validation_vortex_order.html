Validation: Isentropic Vortex Order of Accuracy and Taylor-Green Decay

Smooth-flow accuracy: the translating isentropic vortex and the viscous Taylor-Green vortex

Status: isentropic vortex: validated against the expected second order, a known limit of the method (#2464); 2D Taylor-Green kinetic-energy decay: validated. Code: master at 5838b641c (vortex, Taylor-Green), 3e4c53258 (1D smooth waves). Examples: examples/2D_isentropicvortex (--convect), examples/2D_TaylorGreenVortex, examples/1D_smooth_wave_order. Last run: 2026-11-25.

Purpose

Shock tubes test the discontinuities; a smooth exact solution tests the design order of the schemes. The isentropic vortex is an exact solution of the Euler equations that translates without change, so the error after a translation measures the accuracy of the whole scheme on a nonlinear smooth flow. The 2D Taylor-Green vortex decays at an exact rate set by the viscosity, which tests the viscous terms.

Why the vortex is second order

MFC reconstructs primitive variables. Each cell's conserved averages are converted to primitives cell by cell, and the WENO or TENO reconstruction treats those values as cell averages of the primitives. This is deliberate: in the diffuse-interface multiphase models, reconstructing \(\alpha\), \(u\) and \(p\) keeps a material interface in pressure and velocity equilibrium, whereas conservative reconstruction creates pressure oscillations there (Abgrall's condition; Johnsen and Colonius [36], Coralic and Colonius [18]). The price is on nonlinear smooth flows. The primitive of an average differs from the average of the primitive by \(O(h^2)\), for example \(\overline{\rho u}/\bar\rho - \bar u = \frac{h^2}{12}\,\rho_x u_x/\rho + O(h^4)\). This is a smooth \(O(h^2)\) perturbation of the data the reconstruction receives, so the face states, and with them the flux divergence, carry an \(O(h^2)\) error whatever the WENO order. Wherever the primitives are linear in the conserved variables the conversion is exact and the design order is kept.

In more than one dimension a second, independent limit applies. MFC's finite-volume scheme works dimension by dimension and evaluates each face flux at one point, the face midpoint, from face-averaged states. For a nonlinear flux this is second-order accurate: the face average of the flux is not the flux of the face average. Zhang, Zhang and Shu Zhang et al. [109] show that such schemes are second order on nonlinear multidimensional problems, while for linear problems they keep the full order of the 1D reconstruction. Removing both limits would need a Gaussian quadrature of the flux on each face and a conservative or characteristic reconstruction. MFC does neither, on purpose.

1D smooth waves: which flows reach the design order

The two mechanisms can be separated in 1D, where there is no face quadrature. Two smooth periodic problems were run with the initial condition set to the exact conservative cell averages (10-point Gauss, read through hcid = 170; examples/1D_smooth_wave_order) and the density measured against exact cell averages at the end. HLLC and SSP-RK3 were used, with CFL 0.02 (0.005 for seventh order); halving the CFL changes no digit shown.

  • Linear: a density wave \(\rho = 1 + 0.2\sin 2\pi x\) carried at u = 1 through p = 1 ( \(\gamma\) = 1.4) for one period. u and p are uniform, so the primitives are linear in the conserved variables.
  • Nonlinear: the isentropic \(\gamma = 3\) wave \(\rho_0 = 1 + 0.2\sin 2\pi x\), \(u_0 = 0\), \(p = \rho^3/3\). For \(\gamma = 3\) the Riemann invariants \(u \pm c\) each obey Burgers' equation, so the exact solution follows from the characteristics; it stays smooth until t = 0.80 and is compared at t = 0.2.

  • The linear wave reaches the design order (5 and 7) when the initial condition is the exact cell averages, and only second order from point values: a point value differs from the cell average by \(O(h^2)\), and the scheme carries that difference along.
  • The nonlinear wave is second order for every order and both WENO and TENO, starting from exact averages, in 1D. The fifth- and seventh-order errors agree to three digits (2.61e-7 at N = 256; 1.04e-6 at N = 128 for both). A numpy replica of the same scheme (WENO5, LLF flux) gives 2.61e-7 at N = 256 with primitive reconstruction and 3.3e-10 at fifth order with conservative reconstruction (posted on #2464). So the primitive conversion alone sets the second-order limit of the vortex, and the face quadrature adds a second one in 2D.
  • The WENO order still matters. It sets the error at moderate resolution: on the \(\gamma = 3\) wave WENO3 is 30 times less accurate than WENO5 at N = 32 and 7 times at 256, and on the vortex 5.6 to 3.2 times (N = 64 to 256). It also sets the shock-capturing quality (Validation: Shock Tubes and the Shu-Osher Problem). Above about 64 cells per wavelength, fifth and seventh order give the same error on nonlinear smooth flows.

The convergence tests of the suite (Convergence -> 1D/2D/3D -> WENO5, WENO7, TENO5, TENO7 in toolchain/mfc/test/cases.py, run by run_h_sweep in toolchain/mfc/test/convergence.py on examples/1D_euler_convergence, 2D_advection_convergence and 3D_advection_convergence) assert the design order and pass. They are the linear case above: a density sine carried at uniform u and p, where the average-to-primitive conversion is exact and the flux is linear in the face state, so neither limit applies. They also start from point values but compare the solution with the initial array shifted by a whole number of cells (or after a whole period), not with exact averages, so the \(O(h^2)\) initial-condition difference cancels. They test the reconstruction stencils and weights, not the accuracy on a nonlinear smooth flow.

The 1D Alfven wave of Validation: Ideal MHD reaches fifth order once the time step is small: its density is uniform, so the conversion is exact there too. Its order of 3.0 at CFL 0.4 is the SSP-RK3 time error.

Assessment

  • Isentropic vortex: second order, as expected. Every WENO and TENO variant converges at second order on this nonlinear smooth flow, with the same error constant for fifth and seventh order from N = 64. This is the expected order of primitive-variable reconstruction from cell averages (also in 1D, shown above) and of dimension-by-dimension finite volumes with midpoint face fluxes Zhang et al. [109]. The high-order schemes still have a 3 to 6 times smaller error than WENO3 at moderate N.
  • Taylor-Green: validated. The viscous decay rate is exact to 1e-6 at 32 cells.

Known limitations

  • On nonlinear smooth flows the spatial order is two for every weno_order (see above). The design orders hold where the primitives are linear in the conserved variables and the flux is linear in the face state (uniform-velocity, uniform-pressure advection), and the reconstruction order still sets the error at moderate resolution and the shock capturing.
  • The Taylor-Green check is at a Reynolds number of 1.2e-5 and a Mach number of 3e-4, where the flow is a single decaying mode. The 3D Re = 1600 transition (examples/3D_TaylorGreenVortex) and the IGR Taylor-Green examples are not checked here.
  • The 2D Taylor-Green patch sets the exact initial pressure since #2465 (it was a quarter of it); the table above, measured before the fix, is unchanged at the printed digits (32 cells, rerun after the fix).
  • The time-step order is not measured here: the spatial error dominates the vortex, and the suite covers the RK1-3 orders on 1D advection (Convergence -> Temporal).
  • WENO7 needs at least 36 cells per direction (num_stcls_min * weno_order).

./mfc.sh run examples/2D_isentropicvortex/case.py -t pre_process simulation -n 1 -- --convect -N 128 --order 5
python3 examples/2D_isentropicvortex/check_vortex.py <run N=64> <run N=128> <run N=256>
./mfc.sh run examples/2D_TaylorGreenVortex/case.py -t pre_process simulation -n 1 -- -N 64
python3 examples/2D_TaylorGreenVortex/check_tgv.py <run N=32> <run N=64>

The 1D smooth waves are examples/1D_smooth_wave_order (--problem advect|gamma3, --ic avg|point, --order, --teno, --cfl); its README gives the sweep commands. It is not in the test suite.

--convect also takes --scheme wenojs|wenom|wenoz|teno, --cfl, --t-end and --time-stepper; without it the example runs its original 10-step stationary vortex on a stretched grid. The N = 256 vortex takes about 70 s on one CPU core, the 128-cell Taylor-Green run about 12 minutes. Both examples are registered in the suite at reduced size in their default mode; no test is added here.
