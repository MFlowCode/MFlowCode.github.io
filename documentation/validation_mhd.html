Ideal MHD: Alfven wave, Brio-Wu shock tube, Orszag-Tang divergence error

Status: Alfven wave: validated (exact solution, design order). Brio-Wu: partially validated (grid convergence and the compound-wave states against published values; there is no exact solution to compare with). Orszag-Tang: partially validated (divergence error and mass conservation measured; no reference flow data). Code: master at 5838b641c. Examples: examples/1D_mhd_smooth_alfven_wave, examples/1D_brio_wu_hlld, examples/1D_brio_wu, examples/2D_orszag_tang_hyper_cleaning. See also Validation.

All tables were measured with GNU 13 (CPU, one rank, double precision) on master at 5838b641c unless a row says otherwise.

The example deck itself (1024 cells, WENO3, \(\Delta t\) = 1e-5, CFL 0.011) gives L1( \(B_y\)) = 6.3e-8 and \(|\rho - 1| \le 2.5\)e-8. WENO5 at fixed CFL approaches third order, the order of SSP-RK3; WENO3 is second order on coarse grids, where its weights are far from optimal at the extrema of the sine, and steepens toward its optimal-weight order as the grid is refined (the 4.1 between 256 and 512 cells is pre-asymptotic). The wave amplitude 0.1 is not small, so this checks the nonlinear HLLD fluxes as well as the linear Alfven speed.

Limits: one dimension, so \(\nabla\cdot B = 0\) holds trivially (the divergence error is measured on the Orszag-Tang vortex below); the 2D and 3D versions of the wave are not run.

The preshock state agrees with Ryu and Jones to 0.5 % at every resolution, which is within the precision of values read from a plot. The postshock state is the tip of a narrow peak (the intermediate shock is followed directly by the slow rarefaction), so a cell-averaged maximum underestimates it until the peak is resolved: it is within 0.3 % ( \(\rho\)) and 1.2 % (p) only at 25632 cells, and does not converge monotonically below that. MFC, like the TVD code of Ryu and Jones, produces the compound wave rather than the rotational discontinuity plus slow shock of the other exact solution.

Limits: no exact solution is compared; the reference values for (b) were read from a figure; only the coplanar problem ( \(B_z = 0\)) is run.

The total mass changes by −1.3e-13 over the cleaned run (round-off). The first 200 steps on the CPU (GNU 13.3) give the same \(\epsilon\) and maximum to four digits. From t = 0.16 on the cleaning keeps \(\epsilon\) 4 to 13 times below the uncleaned run, and the uncleaned run stops with NaN at step 900 (t = 0.36), so this deck needs the cleaning. Before that the two runs differ little: the L1 density difference at t = 0.32 is 4.7e-3 of the mean density. The divergence error with cleaning grows to 9e-4 at t = 1 and does not saturate over this time. The maximum, 1 to 3 % from t = 0.24 on, is a cell-centred central difference and includes the jump of B across captured discontinuities, so it bounds the divergence the scheme carries rather than measuring it; where it occurs was not mapped.

Limits: one resolution and one cleaning speed and damping time; the flow field is not compared with published Orszag-Tang profiles; the WENO1 deck 2D_orszag_tang is not measured.
